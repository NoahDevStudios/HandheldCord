## Install

**Windows:** download `HandheldCord-…-win64.zip` below, extract it (for example to `Documents\HandheldCord`) and start `HandheldCord.exe`. The build is not signed yet, so Windows SmartScreen may warn: choose **More info → Run anyway**.

**Linux:** download `HandheldCord-…-linux-x86_64.tar.gz` below, extract it (for example into your home folder) and double-click `HandheldCord`. On the Steam Deck it runs in Desktop Mode.

The setup assistant opens on first start.

Updating: quit HandheldCord from the tray icon, replace the folder and start it again – your settings are kept.

Requires the official Discord desktop app. This is an early preview – questions and bug reports are welcome in the [HandheldCord Discord](https://discord.gg/7mNGV3PtZ4).
